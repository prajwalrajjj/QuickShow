# 🎬 QuickShow

A full-stack MERN movie ticket booking application built with **React, Node.js, Express, and MongoDB**.

## ✨ Features

* User authentication
* Browse movies
* Movie details page
* Seat selection
* Ticket booking
* Admin dashboard
* Responsive UI
* Toast notifications

## 🛠️ Tech Stack

### Frontend

* React
* Vite
* React Router DOM
* Lucide React
* React Hot Toast

### Backend

* Node.js
* Express.js

### Database

* MongoDB

## 📂 Project Structure

```text
QuickShow/
├── client/
└── server/
```

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/prajwalrajjj/QuickShow.git
```

### Frontend

```bash
cd client
npm install
npm run dev
```

### Backend

```bash
cd server
npm install
npm run dev
```
